Palette vs. color-mix()

Every palette shade from 50 to 1300, compared with a translucent mix from that color group's chosen source shade.

Each group has a selectable source shade. The comparison uses only color-mix(in srgb, var(--Blue600) 3.6%, transparent)–style mixes over --Sa-Color-Surface: white in light mode, Gray1200 in dark mode. If the closest result is 0% or 100% source, the mix is left empty because transparency cannot reproduce that shade. ΔE is the remaining perceptual difference in OKLab (lower is closer).

Gray150 is included because it is an existing palette shade. All values are read from the current CSS variables; the mixes are computed independently for each surface.
